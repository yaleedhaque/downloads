Edge — Speech to Text

Self-hosted, on-device AI transcription.

Platforms: Windows / Linux / macOS (self-hosted)

What it is

Edge is a self-hosted speech-to-text tool. Upload any audio or video and get word-timed transcripts with clickable words, plus txt / srt / vtt exports. Everything runs on your own machine — no cloud, no API keys.

Features

  • Word-timed transcripts with clickable words
  • TXT / SRT / VTT export
  • On-device model — no cloud, no API keys
  • Cross-platform

How to use

  1. A packaged build is coming soon — watch this page.
  2. When it ships: install, launch the local app, and upload an audio or video file.
  3. Copy your transcript or export it as txt / srt / vtt.
