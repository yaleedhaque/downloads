YaleDoc

Self-encrypting documents in a single HTML file.

Platforms: any browser (Windows, macOS, Linux, Android) · v1.0

What it is

YaleDoc is a Word-like editor whose documents are encrypted and stored inside a single HTML file (.ydoc.html). Open it offline in any browser, set a password, write, save — the file encrypts itself with AES-256-GCM. Your document never leaves your device; share the file and the password however you like.

Features

  • AES-256-GCM encryption with PBKDF2-SHA256 key derivation
  • A4 / Letter page simulation, themes, auto-lock
  • No install, no cloud, no account
  • One portable file = document + reader + encryption

How to use

  1. Download the blank document below (or try the demo first).
  2. Open the .ydoc.html file in any modern browser.
  3. Set a password when prompted. Demo password: demo1234.
  4. Type your content, then click Save — the file encrypts itself.
  5. Send the file to someone and share the password; they open it the same way. Wrong password = unreadable file.
